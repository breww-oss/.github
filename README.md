# Breww OSS

We're the team behind [Breww](https://breww.com), a cloud-based brewery management platform used by breweries across the UK, Europe, US, Australia, Canada and the rest of the world to run production, sales, stock, distribution, and compliance in one place.

## Why this organisation exists

Like most software companies, we depend on a lot of open source. Some of the packages we rely on have gone quiet — no releases, no responses to issues, security fixes stuck in an open PR for months. Rather than quietly patching our own vendored copies and moving on, we'd rather:

- **Keep these projects alive and usable** for everyone who depends on them, not just us
- **Maintain them in the open**, with normal issues, PRs, and releases
- **Hand maintainership back** to the original authors if they ever want it, or merge upstream if development resumes

This org is where that maintenance work lives, kept separate from our main product repos so it can have its own contribution process, its own CI, and its own life independent of our internal engineering setup.

## What's here

Forks of open source packages (Python and npm, mostly) that we depend on in production and have taken on active maintenance of. Each repo README explains its relationship to the original upstream project, what's changed, and how to contribute.

## What's coming

We're also planning to open source some of our own tooling built at Breww - things we think are useful beyond our own stack. More on that as it lands.

## Contributing

Issues and PRs are welcome on any repo in this org. Check the individual repo's README and CONTRIBUTING notes for specifics, since each project may have its own conventions inherited from upstream.

## Questions

Open an issue on the relevant repo.

## Find out more about Breww

If you're interested to find out more about our software for breweries (and other beverage producers), please visit [breww.com](https://breww.com).
